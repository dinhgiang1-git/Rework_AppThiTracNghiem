## Giới thiệu

Dự án này là một ứng dụng kiểm tra trắc nghiệm (single-choice, multiple-choice, hoặc dạng câu hỏi/đáp án nào đó) được xây dựng bằng ngôn ngữ C# — một phần của bài tập môn học lập trình. Mục tiêu là để học viên rèn luyện kỹ thuật lập trình nền tảng, xử lý giao diện người dùng (console/Windows Forms/WPF?), làm việc với luồng dữ liệu, logic câu hỏi — đáp án, và đánh giá kết quả.
